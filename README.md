## 테스트용 계정

| 구분 | 이메일 | 비밀번호 | 비고 |
|---|---|---|---|
| 관리자 | `admin@b2b-promo.com` | `admin1234!` | 로그인 시 상단 네비에 "관리자" 메뉴가 추가로 노출되어 프로모션 등록/수정 가능 |
| 일반 사용자 | `test-adult@example.com` | `password123` | 펫이 이미 성체 단계로 세팅되어 있어 알→새끼→성체로 키우는 과정 없이 바로 펫 화면 확인 가능 |

새 계정으로 가입하면 알 단계 펫부터 시작한다(로그인 화면에서 "회원가입" 클릭).

## 테스트 시나리오

1. **회원가입/로그인**: 로그인 화면에서 새 이메일로 회원가입 → 자동 로그인 → 프로모션 목록으로 이동. 잘못된 비밀번호로 로그인하면 로그인 버튼 옆에 에러 메시지가 뜨는지 확인.
2. **프로모션 목록/상세**: 목록에서 카드를 클릭해 상세 화면으로 이동(제목/기간/상세 내용 확인, 목록의 간단 내용과 다른 텍스트가 나오는지 확인). 상세/목록 어디서든 "신청하기"를 누르면 그 자리에서 즉시 신청되는지 확인.
3. **찜**: 목록과 상세 화면 양쪽에서 ♡/♥ 찜 버튼을 눌러 토글이 즉시 반영되는지 확인.
4. **나의 신청 목록**: 신청한 프로모션이 "나의 신청 목록"에 신청일과 함께 나타나는지 확인.
5. **펫 화면**: 우상단 "펫 보기"로 팝업을 열어 목욕/밥/쓰다듬기/오늘의 운세 버튼을 눌러보고, 프로모션 신청으로 보유한 특식을 "밥 → 특식"으로 급여해본다(`test-adult@example.com`으로 로그인하면 바로 성체 상태에서 테스트 가능).
6. **관리자**: `admin@b2b-promo.com`으로 로그인 후 상단 "관리자" 메뉴로 이동해 프로모션을 새로 등록하거나 기존 항목의 "수정" 버튼으로 간단 내용/상세 내용/특식 이모지를 바꿔보고, 목록/상세 화면에 반영되는지 확인.
