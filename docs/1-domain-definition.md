# 도메인 정의서: b2b-promo

## 문제 정의
- 회사가 프로모션을 제공해도 신청 경로가 불편해 참여율이 낮다.
- 재방문(MAU) 유인이 없어 사용자가 프로모션을 놓치거나 앱을 잊는다.

## 1. 개요
- **목적**: 회사가 제공하는 프로모션 상품을 신청할 수 있는 앱. 펫(다마고치) 기능으로 재방문(MAU)을 유도.
- **범위**: 회원가입/로그인, 프로모션 신청/찜, 펫 육성. 결제/배송 등은 범위 밖.
- **관련 도메인**: 프로모션 도메인과 펫 도메인은 "특식"으로 연결됨(프로모션 1개당 특식 1개).

## 2. 용어 정의
| 용어 | 정의 | 비고 |
|---|---|---|
| 프로모션 | 회사가 제공하는 신청 가능한 상품/이벤트 | |
| 찜 | 관심 있는 프로모션 표시(토글) | |
| 펫 | 회원가입 시 지급되는 다마고치 캐릭터 | 사용자당 1마리 |
| 특식 | 프로모션마다 1개씩 지정된 펫 전용 먹이 | 해당 프로모션 홍보용 |
| 성장 단계 | 알 → 새끼 → 성체(다 큼) | 성체 이후 순환. 사망 시에는 묘비(임시 상태)를 거쳐 새 알로 |
| 알 상태 | 평범, 더러움, 반질반질, 무지개, 반짝이, 특식 요청 | 알 단계 전용, mood(기분)와 별개. 기본값은 평범 |

| 오늘의 운세 | 버튼을 누르면 랜덤으로 의미 있어 보이는 문구를 보여주는 기능 | 새끼/성체 단계에서 이용 가능 |

## 5. 상태

### 5.1 단계별 행동 · 상태 정리
| 단계 | 목욕 | 밥 | 쓰다듬기 |
|---|---|---|---|
| 알 | eggState → 반질반질, activityCount +1 | eggState 더러움 방지(안 주면 방치→더러움), activityCount +1 | activityCount +1 |
| 새끼 / 성체 | mood "더러움"일 때 → 평범, activityCount +1 | mood "배고픔"일 때 → 평범(또는 특식 급여 시 무지개/진화/반짝이), activityCount +1 | mood "삐짐"일 때 → 평범, activityCount +1 |

- **성장 단계 전이**: 알 → 새끼(activityCount 2회 이상 누적 시), 새끼 → 성체(새끼 단계에서 추가로 3회, 알부터 누적 총 5회 이상 시). 조건 충족 시 50% 확률로 진화(실패하면 activityCount는 유지되고 다음 행동마다 다시 50% 확률로 재도전)
- **성체 순환**: 성체는 시간 경과로 죽지 않음. 대신 성체가 된 지 2주 이상 지나면 새 알 하나를 남기고 사라지며, 이때 선물(할인 쿠폰)을 함께 지급(다시 알부터 시작). 단, 사망 조건(7일 이상 미접속)이 동시에 충족되면 사망이 우선
- **알 상태(eggState) 전이**: mood 없이 별도 상태(평범, 더러움, 반질반질, 특식 요청)만 가짐. 새끼/성체의 mood 전이와 동일한 패턴
  - 기본값은 "평범". 방치(밥을 안 주면)하면 "더러움"(살짝 깨짐)으로, 목욕 행동을 하면 "반질반질"로 변하고, 하루 지나면 다시 "평범"으로 돌아감
  - "특식 요청"도 다른 상태와 동일하게 랜덤으로 뽑힐 수 있고, requestedPromotionId 선정 로직(찜만 한 프로모션 70% 가중치)도 동일하게 적용
  - "특식 요청" 상태일 때 requestedPromotionId 대상 특식을 급여하면 "무지개"로 변화(새끼/성체와 동일 규칙). 요청이 없는데 자발적으로 특식을 주면 10% 확률로 진화하거나 "반짝이"로 변화(나머지 90%는 일반 밥과 동일)
- **기분(mood) 전이**: 새끼/성체 단계에서만 적용. mood는 하루 단위로 유지되며 다음날 다시 랜덤 재설정됨
  - 로그인 시 랜덤 mood 부여. "무지개"/"반짝이"(특별 상태)를 제외한 나머지 상태 중에서 "특식 요청"도 동일하게 뽑힐 수 있음
  - 상태에 맞는 행동(목욕/밥/쓰다듬기) 수행 → 평범(또는 개선된 상태)으로 변화
  - "특식 요청" mood일 때 requestedPromotionId 대상 프로모션의 특식 급여 → 무지개로 변화
  - **특식 요청 대상(requestedPromotionId) 선정**: 신청 완료했거나 기간이 끝난 프로모션은 제외한 나머지 전체 프로모션 중에서 뽑되, 찜만 하고 아직 신청하지 않은 프로모션이 있으면 70% 확률로 그쪽을 우선 요청("특식 줘")해 신청을 유도(나머지 30%는 그 외 후보 중 랜덤). 하루 동안 고정
  - 하루에 3번 이상 접속(재방문)하면 mood가 "행복"으로 변하고 화면에서 돌아다니는 모션을 보임
- **일상 대사**: stage가 새끼/성체일 때, 특식 요청이 없는 평소에는 랜덤 일상어(잡담)를 출력
- **오늘의 운세**: stage가 새끼/성체일 때 버튼으로 이용 가능. 하루 1회만 뽑을 수 있고, 그 날은 같은 결과 유지(다음날 재뽑기 가능)
- **사망**: lastActiveAt 기준 일주일(7일) 이상 미접속 → 펫 사망(다른 전이 조건보다 우선 적용), stage가 "묘비"로 전환되고 "자주 오세요..." 메시지 표시 → 다음 로그인 시 새 알로 교체(activityCount 초기화)

## 6. 비즈니스 규칙 / 제약조건
- 펫은 회원가입 시 1회 자동 생성, 사용자당 1마리만 존재
- 펫의 귀 모양(타입)은 알→새끼로 부화할 때 랜덤으로 정해지고(5종 중 1개) 이후 변하지 않음
- 성체의 팔다리 모양은 1가지로 고정(랜덤 없음)
- 특식은 mood/eggState가 "특식 요청" 상태일 때 급여하면 무지개로 변화
- "특식 요청" 상태가 아닐 때 특식을 주면 10% 확률로 진화(activityCount +1)하거나 "반짝이"로 변함. 나머지 90%는 일반 밥과 동일하게 취급
- 성체 단계에서 5% 확률로 선물(할인 쿠폰) 지급. 단, 마지막으로 받은 지 3일 이내면 지급하지 않음(3일 쿨다운)
- 성체 순환(2주 경과, 알 남기고 사라짐) 시에는 확률과 무관하게 선물(할인 쿠폰) 100% 지급
- 찜 토글은 리스트/상세 화면 어디서나 가능하고 즉시 반영

## 7. 예외 상황
- 신청 기간이 종료된 프로모션은 신청 버튼 비활성화, "담당자에게 연락 주세요" 안내 표시
- 이미 신청한 프로모션 중복 신청 방지
- 신청 취소는 앱 내 기능으로 제공하지 않음. "취소는 담당자에게 연락 주세요" 안내만 표시
- 미접속 기간 초과 시 펫이 묘비 상태("자주 오세요..." 메시지)로 전환되고, 이후 로그인하면 새 알로 교체됨
