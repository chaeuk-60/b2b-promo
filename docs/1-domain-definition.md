# 도메인 정의서: b2b-promo

## 1. 개요
- **목적**: 회사가 제공하는 프로모션 상품을 신청할 수 있는 앱. 펫(다마고치) 기능으로 재방문(MAU)을 유도.
- **범위**: 회원가입/로그인, 프로모션 신청/찜, 펫 육성. 결제/배송 등은 범위 밖.
- **관련 도메인**: 프로모션 도메인과 펫 도메인은 "특식"으로 연결됨(프로모션 1개당 특식 1개).

## 2. 용어 정의
| 용어 | 정의 | 비고 |
|---|---|---|
| 프로모션 | 회사가 제공하는 신청 가능한 상품/이벤트 | |
| 찜 | 관심 있는 프로모션 표시(토글) | |
| 펫 | 회원가입 시 지급되는 다마고치 캐릭터 | 사용자당 1마리 |
| 특식 | 프로모션마다 1개씩 지정된 펫 전용 먹이 | 해당 프로모션 홍보용 |
| 성장 단계 | 알 → 새끼 → 성체(다 큼) | 성체 이후 순환 |
| 상태(기분) | 더러움, 배고픔, 삐짐, 평범, 행복, 무지개 | 로그인 시 랜덤 부여 |

## 5. 상태
- **성장 단계 전이**: 알 → 새끼 → 성체 (조건: 단계별 activityCount가 기준치 도달)
- **성체 순환**: 성체는 시간 경과로 죽지 않음. 대신 일정 조건 충족 시 새 알 하나를 남기고 사라짐(다시 알부터 시작)
- **기분(mood) 전이**:
  - 로그인 시 랜덤 mood 부여
  - 상태에 맞는 행동(목욕/밥/쓰다듬기) 수행 → 평범(또는 개선된 상태)으로 변화
  - 지정된 특식 급여(요청 상태일 때) → 무지개로 변화
  - 찜(관심)만 하고 신청은 하지 않은 프로모션이 있으면, 그 프로모션의 특식을 우선적으로 요청("특식 줘")하여 신청을 유도
- **사망**: lastActiveAt 기준 일정 기간 미접속 → 펫 사망, 알 단계로 리셋(activityCount 초기화)

## 6. 비즈니스 규칙 / 제약조건
- 펫은 회원가입 시 1회 자동 생성, 사용자당 1마리만 존재
- 특식은 mood가 "특식 요청" 상태일 때만 효과 있음(그 외에는 일반 밥과 동일 취급하거나 무효 처리 — 상세 정책은 미정, 미결 사항 참고)
- 성체 단계에서 일정 확률로 선물(할인 쿠폰) 지급
- 찜 토글은 리스트/상세 화면 어디서나 가능하고 즉시 반영
- 특식 요청 대상 선정: 찜은 했지만 아직 신청하지 않은 프로모션이 있으면 그 특식을 요청(신청 전환 유도). 해당 프로모션이 없으면 임의의 특식을 요청

## 7. 예외 상황
- 신청 기간이 종료된 프로모션은 신청 버튼 비활성화
- 이미 신청한 프로모션 중복 신청 방지
- 미접속 기간 초과로 펫이 사망한 상태에서 로그인 시, 사망 처리 후 새 알 지급

## 8. 미결 사항 (Open Questions)
- 사망까지의 미접속 허용 기간(일수) 미정
- 단계별 성장에 필요한 activityCount 기준치 미정
- 성체의 선물 지급 확률 및 순환(알 생성) 조건 미정
- mood가 "특식 요청"이 아닐 때 특식을 줬을 경우 처리 방식 미정
